# Paper Shelf — NFC record

## Public HTTPS URL (write this to the tag)

```
https://symo-creator.github.io/evan-paper-shelf/
```

**Must be HTTPS.** LAN IPs and `localhost` fail for NFC at work.

## iPhone write steps

1. On home Wi‑Fi, open the HTTPS URL in **Safari**.
2. Wait until the offline chip says **Ready**.
3. Share → **Add to Home Screen**.
4. Write the same HTTPS URL to an NFC tag:
   - **Shortcuts** → Automation / NFC, or
   - **NFC Tools** → Write → URL / URI → paste the URL above → Write
5. At work: tap tag → Shelf opens → airplane mode still scrolls Growth + VENOM.

## Notes

- One install on public HTTPS is enough for seeded PDFs.
- User-added PDFs stay in this phone’s IndexedDB only.
